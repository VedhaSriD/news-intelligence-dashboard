# Global News Intelligence Dashboard

A light-themed editorial news dashboard prototype designed to surface fresh, categorized, and credibility-aware global news in a clean, professional interface.

## Current status
This repository currently contains the frontend prototype of the project. The full backend pipeline for news ingestion, deduplication, freshness scoring, and scheduled updates is planned as the next development phase.

## Features
Minimal editorial dashboard UI
Freshness filters (Last 6h / 24h / 48h)
Category-based browsing
Featured story section
Search interface
Credibility and freshness indicators
Bookmark-ready product structure
Light professional mauve-and-cream design

## Planned next steps
FastAPI backend
PostgreSQL database
GitHub Actions scheduler
Deduplication and source clustering
Authentication with Clerk
Archive and bookmark persistence

## Tech direction
Frontend: Next.js / TypeScript / Tailwind CSS / Motion  
Backend (planned): FastAPI / PostgreSQL / GitHub Actions
